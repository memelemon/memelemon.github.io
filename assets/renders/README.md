# Renders

Place selected render images in this folder.

Recommended formats: WebP, JPG or PNG.
Recommended web image size: 1600–2400 px on the longest side; try to keep each file around 1–2 MB.
Use clear file names, for example: `quiet-world-01.webp`.

The gallery page is `renders.html`. Adding an image file to this folder does not automatically publish it in the gallery; the image also needs an entry in that page.
